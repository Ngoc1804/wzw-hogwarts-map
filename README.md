# WIZAMAP V12

Standalone interactive Hogwarts–Hogsmeade UI demo. Open index.html locally. Includes SVG.js, SVG pan/zoom, Anime.js and bundled SVG assets; attribution is included in HTML.

This branch contains the V12 review build. AI Studio test checks remote loading and interactive rendering. WzW Runtime MAP_DATA integration is a separate step; this UI demo uses its embedded sample data.
