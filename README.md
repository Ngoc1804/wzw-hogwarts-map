# WIZAMAP

Open `index.html` for the complete standalone atlas: 11 maps, with live H1 motion and no H2 in this export. Use **Chuyển động: bật/tắt** on H1 and **Tải HTML** to save the standalone file.

H1 keeps all ten village buildings and their positions. Residential models follow the Hogsmeade material style, Hagrid has a hexagonal hut, the station train is aligned to its rails, the stray boat and guide strokes are removed, and the ancient tree is at the north lakeshore.

Open `phase1-assets/index.html` for 305 editable SVG frameworks. All 14 existing house models were replaced; the kit also contains a dedicated hexagonal Hagrid model and map-specific storefronts/elements. See catalog.json, comparison.json, animation-hooks.json and docs/validation.md. Color/decor are applied per map instance.

This branch is the UI/asset demo. Operational WzW Runtime MAP_DATA integration remains separate.
